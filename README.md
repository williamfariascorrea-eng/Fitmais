# Fitmais+ Fitness Center

Institutional website for **Fitmais+ Fitness Center**, a gym in São Lourenço do Sul — RS, Brazil. Modern, animated and fully responsive, built with **React, TypeScript, Vite and Tailwind CSS**.

## ✨ Sections

- **Hero** — bold first impression
- **About** — gym story
- **Benefits** — what members gain
- **Modalities** — classes & training styles
- **Team** — instructors
- **Gallery** — photos
- **Testimonials** — member feedback
- **Trial class form** — lead capture
- **Plans** — membership tiers

## 🚀 Getting Started

```bash
npm install
npm run dev      # opens at http://localhost:5173
npm run build    # production build
npm run lint     # eslint
```
